# IT-помощь Dusit

Приложение-справочник для персонала: поиск по проблемам, инструкции по отделам, связь с IT. Работает без интернета, ставится на телефон как приложение.

## Структура

- `src/app.html` — всё приложение. Контент (карточки, отделы, номер IT) — в самом верху скрипта, блок «КОНТЕНТ».
- `src/sw.js` — офлайн-кэш. Поменял инструкции → увеличь число в `CACHE = 'dusit-help-v3'`, чтобы телефоны получили обновление.
- `src/manifest.webmanifest` — название и цвета для установки на телефон.
- `src/img/` — сюда кладёшь фото для шагов (создай папку), в карточке: `photo: 'img/tv-socket.jpg'`.
- `build.py` — собирает готовую папку `dist/` с иконками.

`CLAUDE.md` — ТЗ проекта. Claude Code читает его сам, когда открываешь папку.

## Как добавить или поправить инструкцию

1. Открой `dist/index.html` в Chrome на маке (или приложение на телефоне) → внизу «Для IT» → «Редактор карточек».
2. «Новая карточка» или тап по существующей. Шаги можно двигать, к каждому прикрепить фото: оно само сожмётся.
3. «Предпросмотр» → «Сохранить». Правки сразу видны на этом устройстве.
4. Чтобы правки попали в сборку: «Скачать cards.json» → положи файл в `DuHelp/src/` → `python3 build.py`. Фото лягут в `dist/img/`.
5. Когда проверил шаги на месте, поставь галочку «Проверил на месте»: уйдёт пометка «Черновик».

Править руками тоже можно: массив `DEFAULT_CARDS` в `src/app.html`. Но если есть `src/cards.json`, при сборке он важнее.

## Сборка

```
pip install pillow
python3 build.py
```

Готовая папка — `dist/`. Её целиком заливаешь на любой хостинг со статикой.

## Важно

- Установка на телефон и офлайн работают только по **https**. Открыть `index.html` двойным кликом с компьютера можно для проверки, но офлайн-режима так не будет.
- Статистика («Помогло» / «Искали и не нашли», ссылка «Для IT» внизу) хранится на каждом телефоне отдельно. Общая статистика появится, когда добавим маленький сервер.
- Не пиши в карточки пароли, IP-адреса серверов и действия, которые может сделать только IT.

## Публикация на GitHub Pages

Сайт раздаётся из папки `docs/`. После правок:

```
python3 build.py
rm -rf docs && cp -r dist docs && touch docs/.nojekyll
git add -A && git commit -m "Обновил инструкции" && git push
```

Через минуту-две изменения появятся по ссылке, а телефоны покажут «Инструкции обновились».
